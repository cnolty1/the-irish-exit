THE IRISH EXIT — VERSION 2

60 drinks with individual JPG images. All images in this package are AI-generated PREVIEWS, including branded bottles and cans. They are NOT verified official product photographs and some labels may be inaccurate. Replace branded images with authentic licensed photos before public-facing use.

HOW TO PUBLISH ON GITHUB PAGES
1. Create a GitHub repository (for example, the-irish-exit).
2. Upload ALL the files INSIDE the irish-exit-site folder to the repository ROOT (not the containing folder).
3. Open Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub to show your site URL, and open it on your Samsung tablet.
5. In Chrome on the tablet, use the menu to Add to Home screen / Install app.
6. Open the site once online and allow it to finish loading before relying on offline access.

Opening index.html directly from a ZIP or Windows folder may not load drinks.json due to browser security. Use GitHub Pages or a local web server to test.
